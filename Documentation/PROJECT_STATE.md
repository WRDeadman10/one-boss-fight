## Gotchas that cost time
- Never delete and recreate an asset that others reference (modal ensure hangs the editor; saved references go empty). Edit in place.
- CDO edits from Python are not saved unless `bp.modify()` is called before compile and save; restart the editor and re-read values to verify.
- Loading a map from a script crashes the editor (use the plugin `open_level` tool); `USkeletalMesh::AddSocket(.., true)` silently adds nothing; Python soft references take the object, not a path; moved or retargeted assets must be checked in a fresh editor (stale paths load as None).
- Bash heredocs with Python triple quotes plus other commands can fail to parse: write patch scripts with the file tool.
- Pack Blueprint function names: older ones have spaces (`Get Current Attribute Value`), newer none (`SetCombatEnabled`): read them with `blueprint_query inspect`.
- Paragon and the third-party packs are git-ignored; Greystone mesh sockets and the layer fixes live only in the local Paragon folder.
- Pack assets edited in place for the player moves (all git-ignored, redo after a pack re-import, backups of the originals were kept outside the project): `GA_Sword/Claymore/Unarmed_Melee` (`FallingAttackMontages`, `Scripts/Editor/air_light_attacks.py`), `GA_Player_MeleeBase_Combined` (selector branch, `Scripts/air_heavy_selector.py`), `GA_BaseHitReaction` (poise by attack power, `Scripts/poise_by_power.py`, run after `install_poise.py`), `BP_CombatPlayerCharacter` (`Scripts/Editor/air_jump_tuning.py`), `BP_ExampleGreatSwordBoss` (`GameplayTags` without `Status.HitStunImmune`, `Scripts/Editor/boss_poise_armor.py`, run before `arena_use_pack_boss.py`), `BP_TargetingComponent` (lock-on aim height and pitch clamp, `Scripts/lockon_aim_height.py`).
- C++ added for the player moves and the boss (no pack edit): `Player/RPGDodgeTiming` (tap, double tap and backward dodge), `Player/RPGBossStagger` (boss stance break and critical window) and `Player/RPGPlayerMovesSubsystem` (attaches them to the pack player and boss when they spawn); `Player/RPGBossEncounter` (boss dormant until the player is within 1200 cm or it is hurt; on a new player pawn it teleports home and resets health, poise, phases) and `Player/RPGBossPhases` (phase two at 50 % health: roar, walk speed x1.2, attack rates x1.2, Attack x1.25, fireballs); PIE drivers `pie_boss_encounter.py`, `pie_boss_phase_two.py`, `pie_boss_fireball.py`; test helper `Combat/RPGInputTestUtils`; `RPGMontageUtils::DescribeNotifies` lists a clip's notifies.
