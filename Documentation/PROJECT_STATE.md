## How to work here
- Build: `powershell -ExecutionPolicy Bypass -File Scripts\Rebuild.ps1 [-Tests]` (closes the editor, builds, runs the automation tests, relaunches with `-nosound`; prints `automation tests: N finished, M passed` or `TESTS DID NOT RUN`). - Tests: `UnrealEditor-Cmd.exe <uproject> -ExecCmds="Automation RunTests OneBossFight; Quit" -unattended -nullrhi -nosound -nosplash`.
- Open editor for scripting: `UnrealEditor.exe <uproject> -nosplash -nosound` (always `-nosound`: audio timeouts stall the game thread). The UnrealClaude plugin serves `http://localhost:3000`. Run a Python file inside it: `MSYS_NO_PATHCONV=1 python -I Scripts/run_in_editor.py Scripts/Editor/<file>.py`. Other helpers: `Scripts/mcp_call.py <tool> '<json>'`, `bp_graph.py`, `bp_pins.py`, `bp_edit.py`.
