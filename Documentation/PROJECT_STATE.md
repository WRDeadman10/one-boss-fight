### Rules that differ from the generic protocol (project rules win)
- NOBODY commits or pushes; the owner commits. No `git checkout`, `reset`, `stash`, `clean` or any command that discards the ~240 uncommitted changes. Never overwrite another agent's uncommitted edit: claim files first.
- ONE editor: UnrealEditor, `Scripts/Rebuild.ps1`, PIE drivers and `RunDrivers.ps1` are used by one agent at a time (the owner hands the editor over: "the editor is yours"). Close the editor before building; launch with `-nosound`; do not run two driver chains at once. The full gate (about 100 minutes) is launched detached. The editor needs an active Windows session (KI-093).
- A claimed file has one editor at a time. Agents that cannot run the editor work on read-only review, C++ that is built later by the editor owner, docs, or new files.
- Never delete and recreate an asset that other assets reference; never edit a pack asset; the roll distance stays 3.2 m; Python drivers never `set_editor_property` on components in PIE (KI-083).
- Never report a test as passing unless it ran: say what was and was not verified (use the driver tables, `automation tests: N finished, M passed`).
