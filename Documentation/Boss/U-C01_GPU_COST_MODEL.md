## Decision use

The only current-build measurement is the Round 4 route baseline. It establishes a GPU-bound gap but does not identify which render pass consumes it. Round 2's fire-shadow result is the best measured low-scope candidate to retest first. Treat every Round 5 result as a proxy experiment, retain repeated baselines, and report individual deltas only if baseline stability is within 5%. The previous report's single-frame ProfileGPU values overlap and do not add to a reliable total. No light, material, post-process, scalability, or shipped-look setting is changed by this model.

Round 3 result files were not present in the checked `Saved/bench_return/r1`, `r2`, or `round4_20261105` evidence directories; no Round 3 numeric row is inferred.
