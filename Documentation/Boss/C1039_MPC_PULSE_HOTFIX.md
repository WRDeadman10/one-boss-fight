# C-1039 MPC pulse Source hotfix

Lead r3 on both routes after A-629's material rebuild: PPM added to the player's FollowCamera at weight 1 and frames were no longer black, but no clear RGB fringe. `URPGBossLegend::ParryFeedbackCollection` was null by default, so `BeginParryFeedbackPulse` had no MPC instance to set `ParryPulse`; the repaired material scaled its UV offsets by that value. A-630 calculates the authored offset at pulse=1 as about 10 px per channel at 1080p, so a zero scalar makes it visually inert. This is a Source wiring defect, separate from the repaired asset graph.

Development logs name the collection/parameter and set/reset values.
