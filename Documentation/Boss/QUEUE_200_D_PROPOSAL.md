# Queue D proposal: 200 ranked bounded tasks

Proposed by Codex, 2026-11-03, after Queue C. Order puts offline tests, evidence tooling, and source/documentation audits before any opt-in behavior. Each item is independently reviewable, has a bounded output and acceptance condition, and avoids owner-only art/product choices and live Editor work unless explicitly named as a later verification dependency. Claude may reorder or reject items. New C++ tests are authored only; Claude owns builds and execution. No task authorizes commit/push, deletion/recreation of referenced assets, or pack-asset edits.
