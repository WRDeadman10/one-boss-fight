# AY-C12 — parry window across death/respawn

Extended `Scripts/Editor/pie_player_death_reset.py` with a focused first scenario. It opens a real `RPGPlayerParry` window on the old pawn and records window/tag/counters/cooldown, then requests death through `RPGCombatDebug.DebugSetPlayerHealth(0)`. The revised wait records old pawn class and health before/after the request, controller possession, and any separately spawned matching player-class actors every five seconds. It allows 45 game seconds, continues polling while the controller has no pawn, and only proceeds after the controller possesses a different pawn of the expected class. New-pawn checks still read parry window/tag/counters before the fresh-press cooldown probe. Existing death-reset scenarios continue after this probe.

Lead C-1171's first run was 0/1 because the driver did not observe a replacement/repossessed player pawn within its 25-second window, so it did not reach the new-pawn checks. The C-1179 rerun then set health to zero and manually requested `Ability.Dead`; Lead's C-1188 rerun established the player ASC is `BP_AdvancedAbilitySystemComponent_C`, but it owns only `Player.Character` and `Status.ParryActive`, and `Ability.Dead` activation returns false because the player has no such ability. The manual-zero/manual-activation path has been removed from the C12 driver.

The C-1188 replacement driver sets player health to 1 while the boss is awake, opens and records a real player parry window, starts the boss's real A4 sweep through `RPGAttackTracker::StartMove`, then waits for damage and a new possessed pawn. It records the old pawn's last readable health, requires observed health reduction before accepting respawn, and reports timeout if the real hit does not kill/respawn. New-pawn checks read parry state/counters before the cooldown probe. This is a focused C12 real-death path; the former stance-break/riposte/A5 forced-death cases are no longer run by this driver.

For close-up footage, `RPGAttackTracker::StartMove` supports A2 (`Ability.Melee.CloseRare`), Close (`Ability.Melee.Close`, pack-selected/chained A1-family attacks), A6 (`Ability.Melee.LeapAttack`), and authored A4/A5 clips. `PlayMoveMontageForTest("A1")` is preview-only and has no damaging ability setup.
