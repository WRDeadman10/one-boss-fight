# Queue AP-C21–C25 — LockOnFraming option

**State:** test-first source implementation complete; BUILD-269 passes on both routes. Owner review remains pending; broader terrain/combat acceptance and B+C combined behavior remain untested.

## Scope and ownership

C-1051 option C says “a lock-on/orbit framing that keeps the boss in front.” The independent `rpg.Camera.LockOnFraming` CVar is Development-only and defaults to `0`. When enabled, it rate-limits the local PlayerController yaw toward the live pack boss and keeps the spring arm on `bUsePawnControlRotation`, so view and pack movement use the same yaw. It retains the control pitch and existing camera collision sweep; it does not rotate/move the player actor or aim attacks.

The rig saves the spring arm's original `bUsePawnControlRotation`, enables it while framing is active, and restores the original value when framing is disabled or the target/controller is lost. Manual grace reads the pack's actual Enhanced Input `IA_Look` Axis2D value; combined input magnitude above the 0.25 deadzone holds automatic yaw for 0.35 s after the input stops. Once grace expires, ControlRotation yaw uses error-proportional `FixedTurn`: speed is `clamp(abs(yaw error) * 6, 60, 360)` degrees/second, using the shortest normalized angular path. This replaces the fixed 120 degrees/second ceiling so a 45-degree error can follow the Lead's 180 degrees/second sprint orbit (up to 270 degrees/second). Values remain provisional for Lead feel validation. Zero horizontal target vectors skip automatic yaw and pitch remains clamped to `PitchMin`/`PitchMax`. If the input action cannot be resolved, the switch fails open to the authored camera rather than infer intent from ControlRotation changes.

The switch resolves only the project pack boss on each enabled tick and only runs for a local `APlayerController` with readable `IA_Look` input. Disable, missing controller/target/input, invalid/nonpositive tick interval, or EndPlay restores the spring arm's original mode and clears tracking state. A target replacement resets the grace timer without changing the saved arm mode. Spring-arm collision and both earlier option switches remain independent.
