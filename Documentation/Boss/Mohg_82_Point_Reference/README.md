# Mohg, Lord of Blood — 82-Point Unreal Combat Reference

**Deliverables**

- `Mohg_82_Point_Combat_Reference.md`: complete evidence-led 82-ID requirement document.
- `Mohg_82_Point_Combat_Reference.docx`: print-friendly Word version with embedded engineering diagrams.
- `Implementation_Patterns_UE5.md`: sequence diagrams, UE roles, C++/Blueprint integration approach.

The `BOSS-QA-008` network/multiplayer requirement is excluded; all other 82 IDs remain unchanged. This is not extracted Elden Ring game code, not measured frame data, and not a current-project audit. The Unreal examples are implementation proposals.
