## 4. How you work on code
- Editor scripting: `MSYS_NO_PATHCONV=1 python -I Scripts/run_in_editor.py Scripts/Editor/<file>.py` (bridge `http://localhost:3000`); log is `Saved/Logs/OneBossFight.log`. Bash heredocs with apostrophes break: write scripts with the Write tool, run them by path.
- Build and restart: `powershell -ExecutionPolicy Bypass -File Scripts\Rebuild.ps1 [-Tests] [-NoRelaunch]` (closes the editor, builds `OneBossFightEditor`, runs the automation tests, relaunches with `-nosound`). The module builds with unity off. If the editor shows a "Restore Packages" dialog the bridge stays dead: delete `Saved/Autosaves/PackageRestoreData.json` before relaunch.
- After each editor start: run `Scripts/Editor/no_throttle.py` and `Scripts/Editor/legend_off.py` (rpg.Legend 0: the legend pass would change the timings the older drivers measure), then a warm-up PIE (`pie_debug_overlay.py`); `Scripts/RunDrivers.ps1` does all of it and prints the regression table (about 100 minutes for the whole list: run it in chunks, `-Only a,b -SkipWarmup`); the first PIE has broken attributes (health 0). Stale slate tick callbacks of a script that did not finish survive until the editor restarts: finish scripts with `unregister_slate_post_tick_callback`; use `pie_stop.py` to end a PIE. An imported asset that is not saved is lost on restart.
- Tests: every feature gets a PIE driver in `Scripts/Editor/pie_*.py` (pattern: step list with delays, `check(name, ok, detail)`, `RESULT n/m passed` line) plus rows in `TEST_PLAN.md`; C++ automation tests in `Source/OneBossFight/Tests/RPGAutomationTests.cpp` (11 tests, all pass). Keep the older drivers passing as regressions: `pie_close_attacks.py` (43), `pie_leap_wave.py` (17), `pie_attack_rules.py` (13), `pie_boss_hud.py` (29), `pie_victory_lock.py` (9), `pie_camera_scenarios.py` (6), `pie_dodge_trials.py`, `pie_riposte.py`, `pie_phase_reset.py`, `pie_fog_gate.py`, `pie_real_kill.py`.
- Useful keys: jump `Gamepad_FaceButton_Bottom`, dodge `Gamepad_FaceButton_Right`, light attack action `IA_NormalAttack` (`RPGInputTestUtils.inject_action`), `Shot ShowUI` console command saves a screenshot with the HUD (whole editor window), `HighResShot 1280x720` saves the 3D view only. The pack destroys the boss about 3.5 s after death. The player has 120 health.
