# S2P-2: adapter/first-read audit and replacement implementation design

2026-10-26. Design + read-only source observations, NOT product hydration code. Claude's D2D_FIELD_TABLES_DRAFT.md is preserved as a proposal, not accepted schema. Generated SOURCE_OBSERVATIONS.json pins38 source files across19 families and indexes224 UPROPERTY declarations/lexical uses. This is broader than the earlier15-family178-property draft, NOT224 approved content fields. It includes nested timing structs, widget internals, delegates and transient fields. The scanner is deliberately not a semantic C++ parser; no “100% hydration” claim.

## Required corrections to the earlier draft

1. EditAnywhere does not mean content; bTestFreeze/bCriticalOnEveryHit and cvar-controlled test policy cannot become ordinary boss authoring knobs by name heuristic. Transient caches/counters/delegates never serialize into a boss definition.
2. Constructor defaults are assigned before ConfigureBeforeRegistration can run. “Before constructor first read” is impossible with NewObject. If ctor only installs defaults/soft paths, override afterward before OnRegister/Initialize/BeginPlay; if ctor consumes a value irreversibly, create an explicit reviewed factory seam. Never pretend post-constructor setter rewinds side effects.
3. Runtime derived state must initialize FROM validated content during BeginPlay, not be hydrated independently: Posture=PostureMax; bleed State.Threshold=InitialThreshold; phase BaseWalkSpeed from actual movement component; Encounter HomeTransform from placed actor. Definitions must not store those sampled mutable values.
4. Registration order is an inter-component input. Death registers OwnClip before Look; Legend last; music/footsteps are outside the earlier property-only table. Tick prerequisites and next-tick timers must be preserved, not reconstructed from UPROPERTY order.
5. Build the immutable typed source record first, then explicit component setter copying only approved fields. No ImportText/SetPropertyByName product adapter, no generic reflection hydration. Reflection may observe test values, not authorize configuration.
6. Public fields are insufficient: runtime-generated Javelin Launch values, loaded flipbook material, music references assigned in Attach, attachment sockets/leader meshes, cvars and hidden fixed update intervals must be classified separately.

## Definition decomposition

BossDefinition: identity + health/posture/phase rules + stance/death/bleed settings + move definitions + presentation/audio references. EncounterDefinition: placed participant slots, home/gate/reset policy and target association. CapabilityProfile: trusted native pack class/property/tag ABI and available adapters. PresentationDefinition: body/pieces/sword/socket, text/audio/VFX. SessionOverrides: existing cvars/test switches, latched under explicit precedence; NOT ordinary serialized content. RuntimeState: generation, handles, weak actor refs, actual health/current posture/montage/collision history; never copied from asset.

Validate finite ranges and typed dependencies BEFORE creating consumers. Missing required field is a named compile error; optional fallback must exactly preserve documented legacy policy and emit provenance. No silent Boss01 default substitution for a new definition. Source pin + effective serialized instance readback are needed: header initializer alone is not actual placed value.

## Blocking proof before adapters can be called complete

- Actual placed/pack serialized override values and transitive assets are not reconstructed from header defaults. Obtain targeted effective-field readback only for needed rows, after account handover; no blind editor export loop.
- Header ClampMin is UI metadata, not runtime validation. Explicit finite/range/ordering checks required; duplicate PhaseId/actionId or missing socket/skeleton/ABI relation reject before object side effects. Zero/off sentinels (GateRadius, HP override, cooldown) must preserve current meaning, not be rejected by generic positivity rule.
- Unit parity must compare an explicit pinned Boss01 fixture against independently enumerated legacy effective settings, not read same default helper on both sides. Otherwise both change together and test stays green. Asset identity/skeleton plus method side effects need runtime witnesses.
- Deferring target rewiring is permitted only for infrastructure acceptance; complete associated-context behavior still gates full step2. No profile may author arbitrary UClass/property names to bypass native adapter whitelist.
- This audit does not declare224 rows implemented. Every runtime state group above is excluded by meaning, not waived requirement; private constants/nonreflected local literals remain review inventory beyond the scanner.
