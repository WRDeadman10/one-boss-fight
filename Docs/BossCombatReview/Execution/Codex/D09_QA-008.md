2026-10-25, Codex. REQUIRED after owner G2/C100; no N/A. DESIGN ONLY. D05 sizing LARGE; networking is cross-cutting, not a disabled future flag or final-week addition. Depends on WP4's accepted-action/entry closure and D07 context identity. No network test has run.

## Assumptions

Standalone acts as authority; listen and dedicated server own combat outcomes. Clients send owned, bounded intent and render replicated decisions. No rollback prediction/rewind promised by the minimum. Safe reversal before release uses the prior complete single-player compatibility binding; it cannot count as QA008 completion. All per-phase networking proofs remain required before final P8 integration.

## Data and runtime

`FRPGAuthorityProfile {Version, DecisionAuthority=Server, ClockDomain, RequestExpiry, ContentManifestHash, AllowedOwnerChannels, RelevancePolicy}`. `FRPGRepAction {EncounterNetKey, Generation, ServerSequence, SourceNetActor, TargetNetActor, MoveId, VariantId, Section, ServerStartTime, PhaseId, TerminalReason, ChosenHold/TargetTransform(optional)}`. Separate `FRPGClientIntent {OwnerActor, Nonce, Command, TargetHint, ClientSampleTime}` is never trusted as the action identity or a hit.

Proposed shared units: RPGCombatAuthorityGateway (owned RPC endpoint), RPGCombatActionRuntime (WP4), RPGCombatReplicator (authoritative action/lifecycle snapshots), RPGServerClockAdapter, RPGCombatContextSubsystem and central RPGDamageResolver. Server validates actual owning connection/source, rate budget, fresh generation, target legitimacy, current state/resources/phase/content and legal channel. Deduplicate nonces; resending cannot reserve twice. Replicate stable IDs/time/section/target/phase/terminal, not montage object pointers or process-local epoch Guid. Required content fingerprint mismatch rejects gameplay participation with a diagnostic. Join-in-progress gets current complete state, not stale start RPC alone.
