## The repair (three edits, tests only)

1. **Assign measurement boundary.** The old capture `OwnedComponentsBefore = Owner->GetComponents().Num()` ran BEFORE `NewStagger(Owner, ...)`; a component created with the actor as outer joins the actor's component set when it is initialized, so the later count was one higher and the assertion `owner gained no component` failed (focused log, one error at the assertion line). The capture is now taken AFTER the fixture and all setup and immediately BEFORE each configure call, as a set of component pointers (identity) and its count, by the helpers `CaptureOwned` / `SameOwned`; the comparison is made immediately AFTER callback A (plan callback) and after the direct config B call. The no-create assertion is preserved and now stronger (identity plus count, per callback), not offset or weakened. A fixture precondition assertion records that the stagger component is already in the owner's set before the callback (this can fail if the hypothesis is wrong, which is intended). The comment above the helpers states the boundary. All 25-field nondefault, state, no-registration and no-begin assertions of Assign are unchanged.
2. **Oracle defaults case.** The authoring defaults of both records (`FRPGParticipantConfig` default-constructed) are a third equivalence case next to ConfigA and ConfigB: the 14 policy fields written by the cluster equal what the DD7 adapter writes, and the oracle leaves the 11 profile fields at the start state, as for A and B.
3. **Oracle no-load / no-package witness.** A new block assigns the real native default profile (seven asset references, from the default-constructed record, no synthetic path) to a fresh component and compares, before and after, for each of the seven paths: `ResolveObject() != nullptr` and `FindPackage(nullptr, LongPackageName) != nullptr`; nothing may appear. It also checks that the seven references were assigned as paths. Limitation (stated in the code): an asset that is already in memory proves nothing for its own path; nothing is loaded, unloaded or registered by the test. No new synthetic `/Game/` literal exists (synthetic paths stay under `/SyntheticMount` and are built from parts).
