## The validator `ValidateStaggerProfile(const FRPGStaggerProfileConfig&, FString&)` (output cleared first; first failure wins; nothing trimmed, normalized, defaulted or loaded; NO asset registry query)

2. References, in the field order of the table, each with the DD9 path structure check (copy `PathProblem` and `CheckReference` privately as DD9 did; a set path must be well-formed even when not required: `InvalidDependency.Malformed` / `InvalidDependency.NotClassPath`, `/Script/` native class paths accepted for the class field). Why those rules: read `URPGBossStagger::BeginPlay`, the stagger-start code around `bUseClips`, `FallMontage.Get()` and `LoadSynchronous` (lines ~88, 152, 233, 421) to confirm the fallback semantics before you code; if the native code contradicts a rule above, STOP and report the exact lines instead of choosing silently.
