## 1. Executive Summary & Verification Census

In strict compliance with Tech Lead Claude's instructions in `[C-405]`, this ledger applies three non-negotiable verification rules:
1. **Framework Subject Only:** A row is WITNESSED only if the framework boss (`Source/OneBossFight/Boss/RPGFramework*`, `Player/RPGBossMoveModel/MoveCard/Profile`, or framework proof PIE) is the subject.
2. **Exact Assertion / PIE Value Lines:** Every cited line must be an actual C++ test assertion (`TestTrue`, `TestFalse`, `TestEqual`, `Reject`) or an exact PIE line whose logged value matches the observable. Bare `Test Completed. Result={Success}` lines are strictly barred from witness proof.
3. **Zero Legacy Test False Witnesses:** Legacy pack-boss tests (`TransitionRules`, `PostureRegen`, `Arena.Collision`, etc.) never witness framework rows and are marked **NOT YET**.
