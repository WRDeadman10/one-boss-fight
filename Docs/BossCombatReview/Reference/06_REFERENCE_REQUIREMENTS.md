# Reference Requirements

These are **reference-derived, project-agnostic requirements**. Bellwarden names, weights and numeric values remain illustrative unless a requirement explicitly asks that the eventual design choose and document its own value. There are **83 requirements**.

## Requirement interpretation note

The package supplies illustrative defaults such as phase threshold `0.55`, context refresh `8 Hz`, reaction latency `0.22 s`, trace samples `6`, posture `100`, and Bellwarden attack timings. A conforming design does not have to copy these values. It must choose, expose, document, and verify equivalent parameters against its actual animation, player kit, arena and performance target.
